E-Commerce Return & Refund Analysis

An interactive Power BI dashboard designed to analyze e-commerce product returns and refund trends. Provides insights into return rates, refund amounts, product categories, sales channels, and return reasons. Helps businesses identify return patterns, reduce refund losses, and make data-driven decisions.

1. Project Description / Purpose

The main purpose of this project is to identify the key reasons behind product returns, analyze return trends across different sales channels and product categories, and provide meaningful business insights to help improve customer satisfaction and reduce return-related losses.

2. Tech Stack

- Power BI Desktop – Dashboard development and data visualization
- Power Query – Data cleaning and transformation
- DAX – Calculated measures and KPIs
- Data Modeling – Relationships and date table creation

3. Data Source

The project uses an E-Commerce dataset containing order, product, return, and refund-related information.
Key data fields:
- Order Date
- Product Name
- Product Category and Subcategory
- Sales Channel
- Total Orders
- Returned Units
- Return Reasons
- Refund Amount
- Average Discount
- Average Return Days

4. Features / Highlights

Dashboard 1: Return & Refund Overview
- KPI cards displaying Total Orders, Returned Orders, Return Rate, and Refund Amount.
- Monthly Refund Amount Trend.
- Returned Units by Sales Channel using a Donut Chart.
- Returned Units and Total Orders by Product Category.
- Return Reason Pareto Analysis.
- Interactive Date Range and Sales Channel Filters.

Dashboard 2: Return Analysis & Product Insights
- Top Return Category and Top Return Reason.
- Average Return Days KPI.
- Average Discount vs Return Rate using a Scatter Chart.
- Return Reason Analysis by Subcategory using a Heatmap.
- Detailed Product Performance Table.

5. Business Impact & Insights
- Identifies products and categories with higher return rates.
- Highlights major return reasons using Pareto Analysis.
- Compares return performance across different sales channels.
- Analyzes the relationship between average discounts and return rates.

Business Benefits
- Reduce product return rates.
- Minimize refund-related financial losses.
- Improve customer satisfaction.
- Identify high-return products and categories.
- Support better inventory and product management.
- Improve overall e-commerce business performance.
